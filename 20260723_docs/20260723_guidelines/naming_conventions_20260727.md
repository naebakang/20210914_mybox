- 함수의 return 값이 True or False 인 경우 함수명은 'check_' 로 시작.
- 함수의 return 값이 True, False 가 아닌 경우 함수명은 'get_' 으로 시작.
- 함수의 return 값이 없고, .csv, .xlsx, .txt, .yaml 등의 파일 형태로 output을 저장하는 경우 'create_' 로 시작.
- 함수의 return 값이 없고, 파일 형태의 output 없고, 여러 함수를 사용하는 경우 'run_' 으로 시작.
- 이 외 함수명은 python 사용자들이 주로 사용하는 규칙을 따른다.
