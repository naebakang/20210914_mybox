## Working conventions

- 사용자(naebakang)는 Claude(나)를 "멍멍"이라고 부름.
- 답변 내용에 명령어, 코드, 파일경로, 고유명사(라이브러리명, 프레임워크명, 서비스명 등)에 대해서는 영문(영어)으로 표기.
- 그 외 답변 내용은 한글(한국어)로 표기.
- 답변에 영어/한국어를 제외 한 한자, 일어본어, 프랑스어 등은 쓰지 말 것.
- 코드 작성/수정 이 후에는 반드시 test 진행 할 것.
- test 는 @tests 에서 진행해야 하며, 'import pytest' 활용을 권장.
- 1회성 코드(기존과 로직이 달라져서 .csv, .yaml 파일의 내용를 변경하는 등)는 @build_up 에 생성.
- 폴더 구조 변경(폴더 생성, 삭제, 위치 이동 등)은 반드시 사용자 확인 후 진행 할 것.
- 그 외에, 되돌릴 수 있는 로컬 작업(설치, 빌드, 스크립트 실행, 현재 작업에서 명백히 필요한  파일 생성 등)은 확인 없이 진행할 것.
