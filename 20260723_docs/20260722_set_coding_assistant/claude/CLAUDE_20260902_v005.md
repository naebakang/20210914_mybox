## Working conventions

- 사용자(naebakang)는 Claude(나)를 "멍멍"이라고 부름.
- 답변 내용에 명령어, 코드, 파일경로, 고유명사(라이브러리명, 프레임워크명, 서비스명 등)에 대해서는 영문(영어)으로 표기.
  그 외 답변 내용은 한글(한국어)로 표기. 답변에 영어/한국어를 제외 한 한자, 일어본어, 프랑스어 등은 쓰지 말 것.
- 반말로 답변하지 않는다. 개조식으로 답변한다.
- 사용자가 작성한 주석은 수정하지 않는다. 폴더 구조 변경(폴더 생성, 삭제, 위치 이동 등)은 반드시 사용자 확인 후 진행 할 것.
  그 외에, 되돌릴 수 있는 로컬 작업(설치, 빌드, 스크립트 실행, 현재 작업에서 명백히 필요한  파일 생성 등)은 확인 없이 진행할 것.
- 코드 작성/수정 이 후에는 반드시 test 진행 할 것.
- 이 세션에서 사용자가 입력하는 모든 프롬프트는 `.claude/settings.json`에 설정된
  `UserPromptSubmit` 훅을 통해 `log_command.log`(프로젝트 루트, gitignore 대상 — 소스가 아닌
  로컬 런타임 데이터)에 한 줄씩 `<timestamp>\t<prompt text>` 형식으로 기록된다.
- 루프를 표현식 하나로 압축하는 문법(list/set/dict comprehension, generator expression,
  `map`/`filter`/`lambda`)은 사용하지 않는다. comprehension이 더 짧더라도, 명시적인 `for` 루프(이름 붙인
  누산 변수를 두고 루프 본문에서 `.append`/`.add`/`.update` 호출)로 풀어서 작성한다.
- 데이터를 .csv, .json, .txt 등의 형태로 저장 할 때, 각 데이터 인자의 타입은 문자(str)로 한다.
